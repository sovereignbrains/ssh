# ssh

Личный SSH-клиент для Windows: сессии и ключи в зашифрованном сейфе, терминал с вкладками и разделением экрана, SFTP, пробросы портов, локальные PowerShell / cmd и Claude Code, работающий на подключённом сервере.

**Скачать:** [последний выпуск](https://github.com/sovereignbrains/ssh/releases/latest) — `SSH-Client-Setup-<версия>.exe`. Установленное приложение дальше обновляется само.

Код приложения, сборка и выпуск новых версий — в [ssh-desktop-app](ssh-desktop-app/README.md).
