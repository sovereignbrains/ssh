# ssh — личный SSH-клиент

Десктопный SSH-клиент на Electron: сессии в зашифрованном сейфе, терминал, SFTP, пробросы портов, локальные оболочки и Claude Code, работающий на сервере через SSH.

## Возможности

- **Сессии и сейф** — подключения, пароли и ключи хранятся в `secrets.vault` (AES-256-GCM, ключ из мастер-пароля через scrypt). Автоблокировка, смена пароля, резервная копия, переносимый режим (папка на флешке).
- **Вкладки** — как в браузере, в заголовке окна: «Главная» (сессии, ключи, пробросы, журнал, настройки), каждое SSH-подключение, локальная оболочка и SFTP — отдельная вкладка. Вкладки перетаскиваются; перетащите вкладку на край терминала — окно разделится (до 4 панелей), заголовок панели обратно в полосу вкладок — панель открепится. `Ctrl+Tab`, `Alt+1…9`.
- **Терминал** — xterm.js, SSH и локальные PowerShell 7 / Windows PowerShell / cmd через PTY. Проверка ключа хоста (TOFU), автоопределение ОС, строка состояния сервера (CPU, RAM, диск, load average, сеть, uptime — раз в 4 секунды, из `/proc`), переподключение на месте.
- **Файлы (SFTP)** — навигация, загрузка и скачивание файлов и папок, перетаскивание из Проводника, переименование, удаление, панель передач с отменой.
- **Пробросы портов** — local forward на `127.0.0.1`, автозапуск при подключении сессии.
- **Проекты** — репозитории GitHub с рабочей копией на сервере или на этом компьютере: клонирование, изменения и коммиты, ветки, pull и push, задачи, пулл-реквесты и сборки GitHub Actions. Оттуда же открывается терминал в папке проекта, её файлы и Claude.
- **Claude** — плавающий чат (кнопка ✦ справа внизу) с Claude Code через ACP (`claude-agent-acp`). Локальные инструменты агента отключены, он работает с сервером выбранной сессии через MCP-инструменты приложения; каждая команда и изменение файла требуют подтверждения.
- **Внешний вид** — темы Edge / Ночь / Авто, разделы «Главной» в доке снизу, уведомления внизу по центру.
- **Синхронизация** — сейф на Google Диске (вход через Google), слияние изменений с разных компьютеров.
- **Журнал** — события сессий (в сейфе) и сбои приложения (`logs/errors.log`).

## Структура

```
ssh-desktop-app/
├── main.js            # Главный процесс: окно, SSH, туннели, PTY, журнал сбоев, IPC
├── preload.js         # Безопасный мост API в окно (contextBridge)
├── vault.js           # Шифрованный сейф
├── sftp.js            # SFTP: просмотр, операции, передачи
├── agent.js           # Claude Code: ACP-адаптер + MCP-сервер SSH-инструментов
├── updater.js         # Обновления из GitHub Releases (electron-updater)
├── sync.js            # Синхронизация сейфа с Google Диском
├── github.js          # Проекты: GitHub API и git на сервере или локально
├── google-drive.js    # Вход через Google (OAuth + PKCE) и Drive API
├── index.html         # Разметка интерфейса
├── renderer/          # Интерфейс: styles.css, fonts, модули по разделам
│   ├── core.js        #   утилиты, состояние, модальные окна, тема, навигация
│   ├── vault.js       #   экран блокировки и сохранение
│   ├── sessions.js    #   подключение и список сессий
│   ├── terminal.js    #   xterm, локальный shell, действия терминала
│   ├── tabs.js        #   полоса вкладок, панели, перетаскивание, строка состояния сервера
│   ├── files.js  claude.js  keys.js  tunnels.js  journal.js  settings.js
│   ├── projects.js    #   проекты: список, страница проекта, git и GitHub
│   └── init.js        #   запуск
├── assets/            # Иконки приложения
└── scripts/before-build.js  # Пересборка нативных модулей под Electron (кроме node-pty)
```

Скрипты `renderer/*.js` — обычные (не модули) и подключаются в `index.html` по порядку; раздел может использовать функции из других разделов только в обработчиках, не при загрузке.

## Разработка

```bash
npm install
npm start
```

Для раздела Claude нужен установленный Claude Code (`npm install -g @anthropic-ai/claude-code`) и выполненный в нём вход.

## Сборка

```bash
npm run build:win     # NSIS-установщик в dist/
```

Бинарник Claude Code из Agent SDK в установщик не попадает — используется установленный у пользователя.

## Синхронизация (Google Диск)

«Настройки → Синхронизация → Войти через Google»: зашифрованный `secrets.vault` хранится в папке **SSH Client** на «Моём диске» (scope `drive.file` — приложение видит только свои файлы). Изменения с разных компьютеров сливаются по записям; на новом компьютере — «Восстановить из Google Диска» на экране создания сейфа.

Для сборки со входом через Google нужен OAuth-клиент типа *Desktop app* (Google Cloud Console, включён Google Drive API, приложение опубликовано). Его данные не хранятся в репозитории:

```bash
setx GOOGLE_CLIENT_ID "....apps.googleusercontent.com"
setx GOOGLE_CLIENT_SECRET "GOCSPX-..."
```

`npm run release` запишет их в `google-oauth.json` (в `.gitignore`) перед сборкой.

## Проекты (GitHub)

«Проекты → Подключить GitHub»: personal access token (classic — права `repo` и `workflow`; fine-grained — Contents, Issues, Pull requests, Actions на чтение и Metadata). Токен хранится в зашифрованном сейфе и уезжает с ним на Google Диск, так что на другом компьютере вводить его снова не нужно.

Проект — это репозиторий плюс папка с рабочей копией: на сервере (путь вида `~/projects/имя`, git должен быть установлен на сервере) или на этом компьютере (нужен git для Windows). Команды git идут через SSH-канал сессии или запускаются локально; токен передаётся через `credential.helper`, читающий переменную окружения, и не попадает ни в список процессов, ни в `git remote`.

## Обновления

Установленное приложение проверяет [GitHub Releases](https://github.com/sovereignbrains/ssh/releases) при запуске и каждые 4 часа (отключается в «Настройки → О программе»). Найденное обновление скачивается по кнопке в заголовке окна и ставится при перезапуске.

Выпуск новой версии:

```bash
setx GH_TOKEN "github_pat_..."   # один раз: токен с правом Contents: Read and write на sovereignbrains/ssh
npm run release                  # 1.1.0 → 1.1.1, сборка и публикация
npm run release -- minor --notes "Что нового"
npm run release -- current       # опубликовать версию из package.json без повышения
```
